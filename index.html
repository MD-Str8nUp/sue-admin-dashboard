A private browser-only dashboard for general workload notes, tasks, deadlines and context Sue wants to give Xena. Calendar and email integrations are not connected. This dashboard does not use client data, credentials, real email addresses or practice integrations. Any future connection requires practice approval first.

Back up before switching devices or clearing browser data. Everything you type here is saved only in this browser on this device. If you clear browser data, use a different browser, or move to a new device, this information will be gone. Use Export JSON backup in the Information for Xena area to save the full dashboard state, and Import JSON to restore it later.
